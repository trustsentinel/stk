# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres
to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-09
Initial tagged release.

### Added
- Go MVP: `stk-hub` broker, `stk-agent` (PTY shell), `stk-client` CLI, and a WebAssembly browser client (xterm.js).
- End-to-end, mutually-authenticated Noise IK sessions; the hub relays ciphertext only.
- Persistent device identities and an SSH-style authorized-clients registry.
- Docker Compose end-to-end demo, Kubernetes manifests with a kind test, and GitHub Actions CI.
